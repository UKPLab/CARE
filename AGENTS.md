# CARE agent instructions

## Pull requests

- Write PR titles and descriptions in simple, plain language. Use short sentences and avoid unnecessary jargon.
- Do not add model names, AI attribution, or agent/tool credits to PR titles, descriptions, or commit messages unless the user explicitly asks for them.
- Follow the PR format in `docs/source/for_developers/contributing.rst`. Include only useful sections and state the changes, checks, and known limits clearly.
