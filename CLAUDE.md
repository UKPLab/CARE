# CARE — Claude Instructions

## Code Style

- Follow existing patterns in the codebase. If no pattern exists for something new, ask before introducing one.
- Follow all guidelines in `docs/source/for_developers/basics/conventions.rst` — this covers naming, JSDoc, socket conventions, Vue style, and the full code review checklist.

## Explanations

After any implementation or suggestion, explain every part in plain language. Assume the reader is a new developer with no prior context about this codebase.
